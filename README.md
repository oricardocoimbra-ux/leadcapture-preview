# LeadCapture — Website Oficial

Plataforma web dedicada exclusivamente à **LeadCapture**, construída com **Next.js (App Router)**, **TypeScript** e **Tailwind CSS**, seguindo rigorosamente a identidade visual Preto, Carvão e Dourado (`#F5B800`).

## Estrutura do Projeto

- `referencias visuais /` — Originais intactos das 51 imagens de referência visual.
- `design/references/` — Cópias organizadas por fase e categoria (uso exclusivo para referência de desenvolvimento).
- `public/images/production/` — Diretório preparado para assets finais de produção.
- `public/logos/leadcapture-logo.svg` — Logótipo vetorial oficial LeadCapture.
- `documentation/` — Inventário visual, folha de contacto, Design System, Sitemap, Mapeamento de Páginas, Arquitetura Técnica e Roadmap.
- `src/` — Código-fonte da aplicação Next.js.

## Comandos

```bash
npm install
npm run dev      # Servidor de desenvolvimento
npm run build    # Build de produção (SSG/App Router)
```
